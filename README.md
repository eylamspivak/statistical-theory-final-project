## Research Question

Can we predict how long an NBA player's career will last based on their
rookie-season performance, and which factors — performance-based and
circumstantial — drive that outcome?

We test four hypotheses:
- **H1:** Higher rookie-season scoring (PPG) predicts longer careers.
- **H2:** Career length differs significantly by draft round.
- **H3:** Age at first NBA season is negatively associated with career length.
- **H4:** Performance and draft round each carry *independent* explanatory
  power for career length, tested jointly in a single nested-model
  comparison.

Full write-up, methodology, and results: [`paper.pdf`](paper.pdf).

## Data

Source: [NBA Players Data](https://www.kaggle.com/datasets/justinas/nba-players-data)
on Kaggle (`all_seasons.csv`, included in this repo for reproducibility).
Covers NBA seasons 1996–97 through 2021–22, one row per player per season.

**Important methodological note:** the analysis restricts to an *incident
cohort* — players whose first recorded season is strictly after 1996–97 —
to avoid misclassifying veterans already active before the dataset's start
as rookies. See `paper.pdf`, Section II.B, for details.

## How to Run

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Make sure `all_seasons.csv` is in the same folder as `nba_analysis.py`.
3. Run:
   ```bash
   python nba_analysis.py
   ```

This prints all statistical results to the terminal and saves 17 figures
(`fig1_distribution.png` through `fig17_nested_models.png`) to the working
directory.

## Known Limitations

See `paper.pdf`, Section IV.B (Limitations) for a full discussion. Briefly:
right-censoring of still-active players' careers, residual left-truncation
(partially but not fully resolved by the incident-cohort filter), and
`player_name` used as a merge key in the absence of a unique player ID in
the source data.
